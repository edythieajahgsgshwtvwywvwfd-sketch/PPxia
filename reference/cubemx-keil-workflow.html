日常循环

VS Code 编辑 → Keil Assistant Build → Download → 板上验证

改硬件配置时

  1. 保存全部文件，并在完整工程根目录做一次版本提交或备份。
  2. 从父目录打开 water.ioc。
  3. 在 CubeMX 修改 Pinout、Clock、DMA、NVIC 或外设参数。
  4. 确认目标工具链仍为 MDK-ARM，打开 Keep User Code 和备份选项。
  5. Generate Code。
  6. 检查 main.c、tim.c、usart.c、gpio.c、中断文件和 water.uvprojx 的变化。
  7. 确认 Keil 工程仍包含 hardware/NVIC/system 下的自定义源文件。
  8. 先 Rebuild，再 Download。

当前项目特别注意

  • 父目录的 CMake 清单不完整，暂时不要把 CMake Build 当作发布固件来源。
  • 只打开 MDK-ARM 时，父目录的 .vscode 配置不会生效。
  • 只打开父目录时，需在 Keil Assistant 中手动选择 MDK-ARM/water.uvprojx。
  • 原版 Keil Assistant 已停止维护；能稳定工作时可继续使用，迁移工具应单独安排，不要与业务改动同时进行。
